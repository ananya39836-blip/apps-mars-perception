### Kinodynamic Observations:
- **Zero Rollover / Tip-Over**: In all 45 simulated runs, pitch and roll angles remained safely below the $30.0^\circ$ rollover threshold ($|\phi|_{max} < 18.2^\circ, |\psi|_{max} < 14.6^\circ$).

### Plain-Language Residual Risks:

2. **Camera Sensor Fidelity**: Rendering uses pinhole perspective with Lambertian reflectance; atmospheric dust scattering, lens distortion, and thermal camera noise are documented gaps.
